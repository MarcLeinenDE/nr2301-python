# Security

Please do not include live secrets or private router data in public issues, pull requests, examples or test fixtures.

Sensitive material includes, but is not limited to:

- administrator passwords
- Wi-Fi keys
- VPN passwords or pre-shared keys
- exported router configuration backups
- SMS contents
- SIM/subscriber identifiers
- live MAC addresses and private deployment-specific IP information

When reporting a bug, replace such values with synthetic documentation-safe examples.

Security-sensitive reports that would unnecessarily expose real credentials or private data should not be filed publicly.
